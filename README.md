# Reinhold Schilling Literature Search Tool (Free Edition)

A browser tool that supports manual pharmacovigilance literature screening of PDF articles.

**Current version:** 1.19.1 (Free)
**Try it online:** https://schilling-vigilance.com/tools/literature-search

## What it does

- Loads PDF articles and searches them against your keyword lists (products, active substances, search terms)
- Keeps keywords in search profiles; example profiles are included
- Shows each hit in its context, with page reference
- Lists excluded hits in the report with their reason, so each decision stays traceable
- Exports a PDF screening report (name, version and edition in the footer)

Everything runs locally in your browser. PDFs and search terms are not uploaded to a server.

## How to use it

1. Download `Literature_Search_Tool_v1.19.1_Free.html`.
2. Open it in a current desktop browser (Chrome, Edge or Firefox).
3. Load your PDFs, enter or import your search terms and run the screening.

The tool loads one helper script (PDFObject) from cdnjs.cloudflare.com for the PDF preview.

## Important limitations

This is a functional MVP prototype for literature screening **support**. It is **not a validated GxP system**. It does not make case or reportability decisions, and it does not replace the qualified review your pharmacovigilance system requires. If you use it in a regulated process, you are responsible for its validation and for documented human review of the results.
